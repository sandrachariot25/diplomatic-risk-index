не подтверждённые самостоятельные политические события и не текстовые наблюдения.

заявления, цитаты и записи GDELT как независимые качественные наблюдения.

Политика МИД РК разрешает собственную прозу по умолчанию KOGL Type 1 с атрибуцией;
новый сбор проверяет отдельные ограничения, стороннее авторство и тип материала.

не обрезается посередине. Роли/группы фиксируются по источнику, статус власти или
оппозиции не выводится догадками. Министерские выступления не получают приоритета.

тайм-аутов транспорта 180 с, без автоматических сетевых повторов. Остались 117
новых URL МИД, один неудавшийся URL и один материал СМИ с нерешёнными правами.

создана `data/backups/pre-schema-004.sqlite3`, проверенная SQLite backup.
Основная база осталась `data/dri.sqlite3`; иных рабочих баз/проектов нет.
