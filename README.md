# Diplomatic Risk Index — корпус документов, заявлений и цитат

Исследовательский прототип, обновление от **1 ноября 2026 года**. Пара: Республика
Корея — Япония; целевой период 2015–2026 (2026 только до даты проверки).
Проект собирает документы, не подключает LLM и не оценивает вероятность конфликта.

Подробности и подтверждения: [аудит источников](docs/SOURCE_AUDIT.md).

Разработка продолжается в исходном проекте, с единственной основной базой
`data/dri.sqlite3`. Текущие численность, охват 2015–2026 по двум странам и типам
источников, неизвестные поля и ограничения: [отчёт качества](docs/QUALITY_REPORT.md).
[Таблица заявлений для ручной проверки](docs/REVIEW_TABLE.html),
[результаты тестов](docs/TEST_RESULTS.txt), [список изменений](docs/CHANGES.md).

### Продолжение небольшими партиями

Команды без `--execute` показывают план и не обращаются к сети. После восстановления
соединения можно продолжить без повторной загрузки завершённых документов:

```powershell

python scripts/expand_corpus.py --batch-size 20 --batches 6 --execute

# Запреты robots и HTTP 401/403/429 этим флагом не обходятся.

python scripts/expand_corpus.py --retry-errors --batches 1 --execute

# Сохранённая позиция NDL: 2020 год, startRecord=41.
python scripts/expand_kokkai.py --year 2020 --start-record 41 --pages 1
python scripts/expand_kokkai.py --year 2020 --start-record 41 --pages 1 --retry-errors --execute
python scripts/expand_kokkai.py --start-year 2020 --pages 5 --execute

# Документированные архивы GDELT; ранее полученные ZIP повторно не загружаются.
python scripts/collect_gdelt_archives.py
python scripts/collect_gdelt_archives.py --execute
python scripts/collect_gdelt_archives.py --timestamps 20151228120000 --kinds gkg --gkg-max-bytes 16000000
python scripts/import_gdelt_archives.py

# Только новые данные этапа, без повторения старых содержательных аудитов.
python scripts/verify_expansion.py
python scripts/run_tests.py
python -m dri stats
```

`dri/expansion.py` берёт существующую очередь, распределяя выборку по её частям.
URL проверяется по document_aliases перед сетью. Контрольные точки, ошибки,
проверка повторного ingestion, темы и распределения находятся в collection_runs /
collection_items основной базы. Известная дата события допустима без даты публикации;
одна дата не подставляется вместо другой. Неизвестные имена/должности сохраняются
неизвестными. Нет числовых весов институтов или источников.

Новый режим полных текстов касается собственной прозы МИД по опубликованной
политике KOGL Type 1 с атрибуцией; отдельные ограничения и чужая атрибуция имеют
приоритет. Вложения/фото не скачиваются. У NDL сохраняется до 90 символов одного
законченного предложения; полный ответ API не архивируется. Статус цитаты
`source_text_verified` подтверждает дословность, а заявление остаётся needs_review.

Миграция **3→4** добавила отдельные gdelt_events / gdelt_mentions / gdelt_gkg;
перед ней создана `data/backups/pre-schema-004.sqlite3`. GDELT хранит исходные
строки, идентификаторы, роли/коды, даты события и регистрации, URL и ограничения;
дата регистрации не объявляется датой статьи. Источник сырой новостной статьи
не считается лицензированным для загрузки текста.

## Запуск

Python 3.11+, сторонних runtime-зависимостей нет. Установка через pip не нужна.
Из корня проекта:

```powershell
python scripts/run_tests.py
python -m dri stats
python scripts/verify_corpus.py
python -m dri collect --limit 2 --transport windows
```

Последняя команда **только печатает план**, без сети и создания БД.
После просмотра плана явный запуск:

```powershell
python -m dri collect --limit 2 --transport windows --execute
python -m dri stats
python -m dri export
```

Для уже обнаруженного исторического пилота:

```powershell
# Только план, без сети:
python scripts/collect_pilot.py --collect-only
python scripts/collect_kokkai.py

# Явное выполнение; повторный запуск продолжает прежний запуск:
python scripts/collect_pilot.py --collect-only --execute --resume
python scripts/collect_kokkai.py --year 2015 --speaker-position 大臣 --run-key kokkai-pilot-2015 --execute --resume
python scripts/collect_kokkai.py --start-year 2016 --speaker-position 大臣 --run-key kokkai-pilot-2016-2026 --execute --resume

# Успешные checkpoints пропускаются; retry ошибок — только после проверки причины:
python -m dri collect --manifest data/pilot_manifest.json --limit 150 --transport windows --run-key official-pilot-2015-2026 --execute --resume
```

Проверка Kokkai также зафиксирована отдельным запуском
`kokkai-normalization-verification`: повторение тех же выборок не создаёт
документов, заявлений или цитат. Первоначальные JSON-отпечатки полного speech
приведены к SHA-256 NFC/whitespace-нормализованного текста только после точного
сопоставления прежнего отпечатка; прежний отпечаток сохранён в метаданных.
Это исправление представления хэша, не замена содержимого или дат документов.

`scripts/collect_kokkai.py` пропускает завершённые годовые запросы при `--resume`.
`scripts/collect_pilot.py --collect-only` использует `data/pilot_manifest.json` и
не запускает поиск повторно. Новый явный run-key нужен для отдельного аудируемого
повторного импорта. Изменённый манифест нельзя молча продолжить под старым ключом.
Выходы и временные файлы ограничены абсолютным корнем проекта; дополнительную
основную SQLite создать через Store нельзя. Тестовые базы — только `:memory:`.

## Схема и миграции

`sources` → `documents` → `statement_sources` → `statements` → `quotes`.
`speakers` хранит наблюдаемое имя/должность с привязкой к дате; `quote_sources`
связывает цитаты с документами, `language_links` — подтверждённые языковые версии.
`duplicate_candidates` хранит пары `possible_duplicate` без слияния исходных
записей. `collection_runs` и `collection_items` — история и checkpoints;
`source_checks` и `discovery_results` — аудит и обнаруженные URL.
Исходные `observations`, `fetches`, `errors` сохранены.

Миграция 3 добавляет только исследовательские метаданные и аудит:
`statement_metadata`, `statement_assessments`, `audit_samples`, `duplicate_reviews`
и представление `signal_timeline`. Перед ней создана одна копия
`data/backups/pre-schema-003.sqlite3`. Основные документы, заявления, цитаты и
кандидаты дублей не изменены; их поля сверяются по отпечаткам до/после аудита.

`statement_metadata` хранит `institution_type`, `speaker_role`,
`political_affiliation`, `government_opposition_status`, дату этого статуса,
`statement_context`, scope позиции, категорию выступающего и тип площадки.
Неизвестные факты остаются NULL. `signal_timeline.statement_date` — только дата
произнесения, без подстановки публикации. Время обнаружения сборщиком хранится
отдельно и не означает историческую доступность документа.

Новые оценки релевантности и предложения уточнения темы хранятся рядом с
исходными аннотациями, а не перезаписывают их. Все 164 пары остаются
`possible_duplicate`: разные даты публикации при неизвестной дате речи не
доказывают ни дубль, ни разные выступления. Гипотеза о ранних парламентских
сигналах не проверялась; структура лишь готовит необходимые признаки.

Миграции в `dri/migrations.py`: версия 1 добавляет сущности и индексы с сохранением
ID документов; версия 2 разрешает неизвестную дату публикации. Перед каждой
миграцией файловой БД SQLite backup создаёт `data/backups/pre-schema-NNN.sqlite3`,
проверяет его целостность, затем выполняется транзакционная миграция с проверкой
FK и записью версии. Существующий backup не перезаписывается. Это резервные копии,
а не альтернативные рабочие базы. Автоматического отката поверх текущих данных нет.

## Документ, заявление и цитата

Документ — самостоятельная публикация или официальный датированный transcript
одного выступления. Заявление — конкретный эпизод высказывания с явной идентичностью
`event_key`, страной, органом, выступающим/должностью и контекстом. В Kokkai единица
— один официальный speechID (реплика в заседании), не целое заседание. Цитата —
дословный короткий фрагмент опубликованной языковой версии, а не пересказ автора
новости. Заголовок статьи или сообщение о встрече сами по себе заявлением не считаются.

Один проверенный event_key в Reuters/Yonhap/NHK добавляет источники к одному
заявлению. Без доказательства общего выступления автоматического объединения
нет. Совпадение текста в другую дату или при другом event_key сохраняет обе записи
и создаёт возможный дубль. Частичное сходство также только кандидат на проверку.
Языковые версии объединяются под одним подтверждённым выступлением и отдельно
связываются через `link_language_versions` с URL доказательства и проверяющим;
автоматического перевода или межъязыкового смыслового слияния нет.

Дедупликация документов использует нормализованный URL, официальный ID, дату
и SHA-256 нормализованного текста; одинаковый текст другого дня остаётся отдельным.
Повторное получение не создаёт повторных сущностей и связей. Изменение текста
сохраняется как новая версия документа. Для metadata-only вместо неизвестного
текстового хэша используется отпечаток библиографической идентичности с явной
меткой `fingerprint_kind=metadata_identity`.

`spoken_date` и `published_date` различаются: у Kokkai известна дата заседания,
но дата публикации остаётся NULL. Должность берётся из записи на соответствующую
дату; у безымянного пресс-секретаря имя остаётся NULL. Уровень уверенности в
атрибуции — категория high/medium/low/unknown с объяснением, а не вероятность
конфликта и не вес источника. `needs_review` не означает ручную верификацию.

`--transport windows` требует PowerShell 7 (`pwsh`) и использует системное
доверие Windows с проверкой TLS. На других платформах используйте стандартный
`--transport urllib`. При ошибке сертификата исправляйте доверенную цепочку;
отключения проверки сертификатов в проекте нет. Установка новых пакетов не
производилась. Если системный `python` указывает на Windows Store alias,
укажите путь к рабочему Python 3.11+.

## Данные и происхождение

- `data/dri.sqlite3`: документы, наблюдения, HTTP-запросы, ошибки.
- `data/raw/<prefix>/<sha256>.bin`: неизменённые байты ответов коннектора.
- `data/corpus.jsonl`: тексты, метаданные, ссылки на оригиналы и raw-файлы.
- `data/errors.jsonl`: ошибки, также записанные в SQLite.
- `data/audit/*.json` и `*.bin`: отдельные точечные пробы аудита, включая
  ответы отказа; код HTTP 200 сам по себе не подтверждает корректность API.
- `data/manual/`: HTML, ранее сохранённый через Invoke-WebRequest; это
  перекодированные UTF-8 снимки, не исходные сетевые байты.

SHA-256 использует NFC и нормализованные пробелы. Разные URL одинакового текста
одного дня сохраняются как алиасы/наблюдения. Межъязыковые и смысловые дубли
автоматически не объединяются.
Время получения UTC, дата публикации — календарная дата источника без выдуманного
времени. `author=null` означает отсутствие явно указанного личного автора;
издатель и роль spokesperson хранятся отдельно. Английский текст корейского МИД
может быть помечен самим источником как unofficial translation.

Локальный импорт разрешён для HTML, полученного доступным законным способом:

```powershell
python -m dri import-html --source mofa_kr --url "https://www.mofa.go.kr/eng/brd/m_5676/view.do?seq=315568" --file data/manual/korea-315568.html
```

Такой импорт помечается `provenance=user/local HTML import`, не выдаётся за
успешный HTTP-запрос. Новое тело HTML не сохраняется, применяется ограничение
текста политикой источника. Не импортируйте страницы отказа как документы.

## Ограничения текущей реализации

Корейский коннектор проверен на настоящем HTML 2015 года. Японский коннектор
содержит экспериментальный HTML-парсер, проверенный **только на синтетической
фикстуре**: доступ к хосту при аудите отклонён HTTP 403. Его селекторы ещё нельзя
считать подтверждёнными; при несовпадении структуры он завершится ошибкой.
Включение японского seed в план не означает успешный сбор.

Сеть выполняется последовательно, минимум 5,5 секунды между запросами. Указания
robots.txt могут увеличить паузу. 401/403/429 останавливают хост на оставшуюся
часть запуска, автоматических повторов нет. Неизвестные robots.txt и HTML вместо
robots.txt останавливают сбор; 404/410 robots.txt трактуются как отсутствие правил.
Обычные cookie-редиректы строго на тот же URL обрабатывает Windows transport;
прочие редиректы проверяются по списку хостов и robots.txt. Нет обхода блокировок,
параллельного сканирования, вложений, прокси-ротации или headless-браузера.

`scripts/probe.py` — отдельный диагностический инструмент с явно заданными URL;
он не является crawler и не проверяет robots.txt автоматически. Перед его
использованием нужно самостоятельно проверить план, правила и допустимость
целевых адресов. Он не предназначен для массовой загрузки.

Для Kokkai предусмотрено узкое исключение: robots.txt перенаправляет на главную,
а официальная спецификация явно разрешает машинный API-доступ без регистрации.
Поэтому разрешён только опубликованный `/api/speech`, последовательно с паузами;
это не применяется к Disallow, 401/403/429 или другим ресурсам.

## Сохранение и права

Два исходных полных текста и их raw-файлы оставлены без изменений как
`legacy_unreviewed`. Новые полные тексты не сохраняются. Для институциональных
корейских заявлений сохраняется не более 25 слов, для японских стенограмм —
не более 90 последовательных символов. Это технические пределы короткого
исследовательского цитирования, не универсальная лицензия на распространение.
Для СМИ — только метаданные и ссылки; надёжность/тип записаны в sources без весов.
Права отдельных выступающих Kokkai не объявляются переданными в public domain.

Исходный ответ новых запросов хэшируется в памяти; `fetches.raw_path=NULL`
означает, что тело не сохранено. В observations пустой raw_path означает только
хэш/ссылку на получение. Время запроса и хэш остаются проверяемыми метаданными;
воспроизвести полный текст по хэшу невозможно. Архивные raw-файлы проверяются
отдельно. Повторная проверка всех реальных доменных записей —
`python scripts/verify_corpus.py` — проходит офлайн и не создаёт новые сущности.

Пилот ограничен выборкой, а не доказательством полноты. GDELT реализован как
проверяемый модуль обнаружения (DOC recent window), не как архив статей 2015–2026;
в текущем запуске прежний 429 не обходился. Полный сбор лицензируемых СМИ,
неподтверждённые API и закрытые страницы не включены.

# Экономический корпус DRI

Экран «Экономические отношения» открывает месячные потоки, структуру торговли по CPA 2.1, зависимость по HS6 и зеркальную сверку. Экономические данные хранятся в таблицах `economic_*` базы `data/dri.sqlite3`. Последние версии доступны через представления `economic_trade_current` и `economic_trade_native_current`. Модель политического DRI использует свой прежний набор данных.

## Источники и покрытие

| Источник | Период | Данные |
|---|---|---|
| МВФ IMTS | январь 2015 — июль 2026 | 8 USD-потоков за месяц, 139 общих месяцев. Отдельные отчёты каждой страны, торговля с партнёром и миром. |
| Таможенная служба Республики Корея | август и сентябрь 2026 | Дополнение из подробных таблиц бюллетеней, млн USD. Даты публикации и номера страниц сохранены. |
| Минфин Японии / e-Stat | январь 2015 — сентябрь 2026 | Экспорт, импорт и суммы по странам в исходных тысячах JPY. 24 официальных CSV с месячными колонками. |
| OECD BTiGE | 2015–2024 для обеих стран, 2025 дополнительно для Японии | Годовые продуктовые ряды CPA 2.1, мир и партнёр. Панель стран-поставщиков для выбранных отраслей. |
| UN Comtrade | Япония январь 2015 — август 2026, Корея январь 2015 — декабрь 2025 | 8 338 месячных записей по девяти HS6. Годовые панели поставщиков за 2015–2025 по 850760, 854232 и 848620 содержат ещё 2 526 записей. Пустые ответы остаются пропусками. |

Открытый Comtrade ограничивает выдачу, а полный архив требует авторизации. Импорт отклоняет ответы, достигшие предела 500 строк, и хранит пустые ответы в журнале загрузок. Прямой API KCS для массовой выгрузки требует ключ data.go.kr. Использованы общедоступные бюллетени с детальными таблицами за два недостающих месяца. Октябрьский пресс-релиз KCS содержит мировой итог, но этого недостаточно для полного двустороннего наблюдения.

## Расчёт и доступность

- Оборот и сальдо рассчитываются отдельно по репортёру. Зеркальный разрыв сопоставляет экспорт FOB и импорт партнёра CIF. Ряды двух репортёров описывают один коридор, поэтому их обороты не суммируются. Скользящие средние требуют 3 или 12 последовательных полных месяцев. Годовые сравнения неполного года используют одинаковые месяцы.
- МВФ публикует исходные суммы в USD. `SCALE` сохраняется как атрибут отображения. ОЭСР публикует значение с отдельным множителем `UNIT_MULT`. Национальный японский ряд остаётся в тысячах JPY. Знаменатель для национальной доли — сумма строк стран в том же CSV. Для сверки с МВФ используются доли без валютной конвертации.
- Импортная зависимость равна доле поставок партнёра в импорте того же товара или отрасли из мира. Структурная доля CPA использует двусторонний итог `_T`. Строки CPA могут представлять пересекающиеся уровни классификации. По этой причине сумма всех строк не имеет экономического смысла. Годовое изменение доли выражено в процентных пунктах.
- HHI рассчитывается по именованным отдельным поставщикам с мировым итогом в знаменателе. Нижняя граница — сумма квадратов известных долей. Верхняя прибавляет квадрат нераспределённого остатка. Таблица показывает покрытие, число поставщиков и крупнейшего наблюдаемого поставщика. Страны и территории сверяются со справочником ООН. Географические агрегаты исключены.
- Для товаров сохраняются оригинальные редакции HS. Таблица соответствий UNSD однозначно связывает четыре из девяти выбранных кодов в HS 2012, 2017 и 2022. Они сопоставляются между редакциями. Для остальных пяти кодов график и годовые изменения разделены по редакциям. Аудит и контрольная сумма источника находятся в `trade_hs_alignment.csv`. Сопоставимый отраслевой слой использует конверсию ОЭСР в CPA 2.1. HS 280920 охватывает фосфорную и полифосфорные кислоты в целом. Специализированные марки аккумуляторных материалов по этому коду не выделяются.
- Дата периода, дата публикации при наличии, дата загрузки и статус версии сохраняются раздельно. Для исторических рядов МВФ, ОЭСР и Comtrade используются текущие архивные версии. Их наличие на дату старого прогноза не установлено. Архивы с SHA-256 и URL хранятся в `data/raw/trade`.

## Воспроизведение

```powershell
# Пересчёт из сохранённых исходников, без сети
.\.venv\Scripts\python.exe scripts/economic_trade.py

# Повторная проверка соответствий HS из сохранённой таблицы UNSD (openpyxl)
.\.venv\Scripts\python.exe scripts/economic_trade.py --audit-hs

# Загрузка или продолжение с последнего сохранённого месяца
pwsh -NoProfile -File scripts/fetch_trade.ps1 -AggregatesOnly
pwsh -NoProfile -File scripts/fetch_trade.ps1 -JapanOnly
pwsh -NoProfile -File scripts/fetch_trade.ps1 -KoreaOnly
pwsh -NoProfile -File scripts/fetch_trade.ps1 -ProductsOnly
pwsh -NoProfile -File scripts/fetch_trade.ps1 -ConcentrationOnly
.\.venv\Scripts\python.exe scripts/economic_trade.py

# Обновление последних версий
pwsh -NoProfile -File scripts/fetch_trade.ps1 -AggregatesOnly -Refresh
pwsh -NoProfile -File scripts/fetch_trade.ps1 -ProductsOnly -From 2026-07 -Refresh
pwsh -NoProfile -File scripts/fetch_trade.ps1 -JapanOnly -From 2026-01 -Refresh
.\.venv\Scripts\python.exe scripts/economic_trade.py
```

Команда импорта не дублирует сохранённые версии. `-Refresh` архивирует новую версию ответа. Параметр `-Through` по умолчанию указывает на предыдущий календарный месяц. Для годовых панелей берутся завершённые годы. Бюллетени KCS за новые месяцы добавляются в список проверенных ссылок после проверки структуры таблиц.

На 9 ноября 2026 года сохранены 1 120 месячных потоков в USD, 564 национальных месячных потока в JPY и 41 970 товарных и отраслевых записей. Из последних 31 106 приходится на OECD BTiGE, включая 83 кода CPA и служебных итогов. В интерфейсе выделены 10 отраслевых рядов. Доли рассчитаны для 3 858 строк HS6 по импорту и экспорту, а годовые границы HHI доступны для всех 66 комбинаций страны, года и одного из трёх выбранных товаров. Медианный абсолютный разрыв между зеркальными потоками составляет 4,62% от заявленного экспорта. Национальная сверка японских долей с МВФ даёт среднее абсолютное расхождение 0,0065 процентного пункта.
